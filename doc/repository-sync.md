# 远端源码范围

目标仓库：https://github.com/wsjq5477/MA-Relay 。本页只说明仓库里有什么、哪些材料留在本地，以及本地资料检查的前提；公开预发布的标签、冻结提交、EXE 字节与 SHA-256 按版本集中登记在[历史发布登记](iterations/release-ledger.md)（未列入的中间版本见对应迭代专项），当前发布状态见[资料入口](README.md)。

仓库包含源码、测试、构建脚本、依赖锁文件、模块设计和迭代资料。原生配置、开发运行状态、凭据、含敏感数据的原始验收材料、依赖目录、构建输出和 Windows EXE 保留在本地，不随源码提交。历史文档中的实际任务、请求和会话标识已脱敏。

文档中 `artifacts/` 和 `desktop/release/` 的相对链接指向本地原始材料；本轮筛选的issue27/28合成测试日志、独立CI结果、摘要与脱敏截图随源码公开；隔离profile、认证文件、原始备份及发布认证辅助文件不公开；其他原始材料仍不随克隆提供。报告保留原日期、证据级别和未测项，不能把源码同步当作重新执行历史验收。

`node scripts/check-docs.mjs` 检查完整本地资料，其中包含原始材料和发布包。仅有源码的克隆缺少这些链接目标时，应补齐经授权的本地材料后再执行完整资料检查，不能据此声称历史验证已通过。源码同步时的沙箱执行结果作为当时记录保留在[历史发布登记](iterations/release-ledger.md)。
