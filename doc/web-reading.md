# 网页文档阅读与维护

网页发布 `doc/user/` 的当前用户说明；仓库完整的实现设计、测试报告、问题与迭代分别保留原位置，供维护者使用，不进入网页、搜索、静态资源或下载链接。

## 启动与阅读

```bash
npm ci
npm run docs:dev
```

打开 `http://localhost:4188`。目录分为开始使用、功能设计、原生Agent与接入方式；右侧目录跳转当前章节，顶部提供全文搜索与主题切换。首页提供六方式接入总结，DSH专章说明三个入口。

## 修改规则

用户正文在 [doc/user](user/index.md) 中直接维护，不另写HTML。修改能力或操作流程时同步相应用户页与内部完整设计；内部编号、问题/测试/历史/开发记录只保留在内部材料。用户页必要的版本可用性和兼容范围应准确标注。

页面清单与两张摘要表的生成规则由 [发布清单](../scripts/doc-site-content.mjs)集中维护。新增用户页需登记清单与导航；新增Agent还须同步原生章节、内部接入矩阵与静态注册能力。表格只提取当前方式与能力，不发布内部矩阵中的规划、源码定位和验收段落。

## 检查与构建

```bash
npm run docs:check
npm run docs:test
npm run docs:build
npm run docs:preview
```

现有用户Markdown在开发模式热更新；修改页面清单、适配器能力或内部矩阵时重新运行准备脚本或重启服务，以刷新生成表格。构建结果为 `doc/.vitepress/dist`，默认预览在4188；`docs:build`包含独立发布范围审计。

准备脚本仅复制明确许可的品牌图片，不再导出源码、日志和验收证据。公开页面不链接内部资料；开发资料继续从 [仓库资料入口](README.md)阅读。

验证方式与本地浏览器证据见[M11报告](modules/11-documentation-portal/test-report.md)。当前未部署公网；本地文档检查不连接原生Agent或模型。
