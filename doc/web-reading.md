# 网页文档阅读

更新：2026-10-12。文档站读取本仓库 `doc/` Markdown，与人类和 Agent 编辑的文件一致。

## 启动

在仓库根目录执行：

```bash
npm ci
npm run docs:dev
```

浏览器打开 `http://localhost:4188`。左侧目录查看整体设计、模块设计/报告和迭代；右侧目录跳到本页章节。顶部搜索支持全文检索，主题按钮切换深浅色。

## 修改与构建

修改现有 Markdown 后开发站点自动刷新；新增模块或迭代后重启文档服务，目录会重新扫描。无需维护另一份网页正文。

```bash
npm run docs:check
npm run docs:build
npm run docs:preview
```

构建输出在 `doc/.vitepress/dist`；preview 在本机 4188 端口阅读构建结果。更新证据或引用源码文件后重新启动/构建，以刷新引用资源副本。只启动文档站，不连接 Agent、服务器或模型。

## 文件下载范围

文档内部链接正常导航。显式引用的源码、脱敏报告和图片作为静态阅读/下载资源导出。隐藏开发状态、凭据、数据库、私钥和 EXE 不由网页导出；它们的原路径保留在仓库资料中。

历史综合快照不加入网页全文搜索，历史入口仍保留；当前设计与迭代记录是主要阅读内容。当前网页仅本地运行，未部署到公网。
