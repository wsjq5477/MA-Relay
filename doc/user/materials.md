# 工作材料

公共工作材料集中展示协作中的文档、任务和消息，帮助用户与 Agent 获取同一份可引用内容。它独立于各个原生 Agent 的私有聊天。

## 阅读与复制

在工作材料入口查看索引与 Markdown 视图，按任务和材料版本定位内容。页面支持阅读、复制，以及当前页索引或单份 Markdown 的下载。

材料的修订版本用于确定“读到的是哪一份”。材料可见、任务执行成功、目标机器可达是不同状态，不能仅凭读到一份文档推断任务已完成。

## 选择材料生成只读包

围绕同一工作目标，明确选择需要的材料和版本，核对预览，再导出 Markdown 或 JSON 的本机副本。它适合整理要交给下一个 Agent 的必要上下文。

当前选材包提供只读整理、预览和导出；生成或下载不代表已发送给某个目标，也不确认对方收件、读取或执行。

## 与任务和权限的关系

材料包不会新建任务、迁移原生会话或扩展授权。若要让其他 Agent 开始工作，需要通过直接会话或获准的委派提交需求。

不要将无关凭据和私人配置加入公共材料；模型账号与机器连接凭据应继续由各自原生工具和连接设置管理。
