# 任务与会话

会话承载连续对话，任务表示一次实际提交。Bridge 将任务与原生工具的会话对应起来，使续聊、输出查询和取消都指向正确的执行。

## 新建与续聊

选择机器、Agent 和该机器上的工作目录，再提交需求。任务完成后，在原会话输入下一条消息，使用原生续聊能力继续工作。

换工具、换机器或复制工作材料不会迁移原生会话。DSH Desktop / Web 当前只继续由 Bridge 创建并关联的会话，不导入原生界面里任意已有的聊天。

## 读懂任务状态

| 状态 | 含义 | 操作建议 |
| --- | --- | --- |
| 已接收 / 等待 | 请求已登记，尚未确认完成 | 等待后续状态与输出 |
| 执行中 | 原生 Agent 正在处理 | 查看输出，必要时处理原生交互 |
| 成功 | 当前任务返回成功终态 | 阅读结果，按需续聊 |
| 失败 | 原生执行或连接返回明确失败 | 根据错误修复配置，再决定下一步 |
| 已取消 | 原任务取消已完成核对 | 按需发起新的工作 |
| 未知 | 暂时无法确认原任务最终结果 | 查询原请求，避免重复提交 |

“收到取消请求”不代表已经取消；权限回复已接收也不代表任务执行成功。结果以原任务后续状态为准。

## 权限与输入

Claude Code 与 OpenCode 支持部分原生权限回复；OpenCode 还支持已适配的结构化输入类型。其他入口当前不提供 Bridge 权限回复，须按原生工具要求处理。

Claude Code 的结构化提问尚不能在 Bridge 表单内回复。DSH 服务中的权限或提问需要在 DSH 原生界面完成。详见[各 Agent 功能对照](agents/index.md#功能对照)。

## 取消与连接中断

使用当前任务的取消操作，再等待结果核对。网络中断、后台重启或结果暂缺时，保留原请求并查询它；不要通过另起会话、换节点或重复发送相同需求来判断原任务是否完成。

任务状态说明原生执行结果，业务目标是否满足仍需阅读输出、文件与产物。
