# 快速开始

本页按本地alpha.62候选说明。公开alpha.60仍有桌面新建/续聊等旧入口；升级后日常需求从原生Agent会话发起。

## 准备原生 Agent

在任务实际执行的机器上安装并配置原生 Agent，先确认它自身能正常工作。AgentBridge 沿用它的账号、模型、工具和项目配置，不另建模型供应商配置。

[原生 Agent 适配](agents/index.md)列出每个入口的执行方式和支持功能。DSH 的服务入口有单独的[连接说明](agents/dsh.md)。

## 添加机器并发现 Agent

打开 AgentBridge 的“接入配置”页面，使用本机或添加 WSL / SSH 机器，再执行工具检测。Windows 和 WSL 是不同运行环境，各自的命令、目录与配置分别发现。

选择已发现的 Agent，确认机器在线、可执行程序或服务连接可用。安装检测只说明找到了工具；第一次实际任务才能确认原生账号和模型连接是否可用。

## 配置协作入口

在“接入配置”选择可调用Bridge MCP的主Agent，保存它与获准目标的关系。打开原生工具行“配置”，添加或导出Bridge MCP配置，再按原生工具要求重新加载并核对实际工具目录。写入配置、加载、连接和工具可用分别判断；详见[MCP与连接授权](connections.md)。

只保存关系或生成配置不会发起任务；模型、账号和工具权限沿用原生设置。

## 从原生会话提出需求

打开你已配置的原生Agent，在原会话输入目标与完成要求。主Agent可通过获准的Bridge MCP发现目标、委派、查询原任务与取得结果。需要访问已有文件时，明确目标机器上的工作目录；不要把本机路径当成远端路径。

小队协作先在“小队设置”登记成员、建立小队及工作作用域，再为各成员生成工作MCP配置。建立作用域只保存目标、标准与访问范围；成员从自己的原生会话处理分工、任务报告、文档与验收。预算、成员访问及编辑权限由你配置。

## 查看结果与恢复原执行

“执行审计”“会话审计”保留Bridge关联的原任务、各轮回答与来源；原生工具独立处理且未经过Bridge的聊天不会自动导入。桌面不提供新建或续问输入框，继续工作回原生会话。

日常权限确认在原生工具处理。需要恢复已有Bridge执行时，在“执行审计”打开原任务并显式选择“处理这条原执行”，按适配能力处理原权限、输入或取消；退出恢复后回到只读。回应未知时查询原请求，不换ID或重复发送。[任务与会话](sessions.md)说明这些状态的含义。

需要更换 Windows 程序时，先在“设置 → 后台运行 → 停止后台并退出”结束旧后台。远端机器后台需要在对应机器的维护入口单独更新。
