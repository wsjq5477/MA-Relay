# I04 需求与验收标准

Windows 桌面看板是 CLI 已有能力的可视化入口，复用真实 OpenCode 和同一份任务记录。用户已要求开发；范围按三个可验收增量组织。

| 需求 | 功能及规则 | 验收标准 | 增量 |
| --- | --- | --- | --- |
| D01 桌面入口 | Windows x64 原生窗口、单实例、窗口控制、中文导航、浅色/深色/系统主题 | Windows 进程实际启动；五页可操作；主题保存并重返；不需要常驻终端 | M1 |
| D02 发现连接 | 自动扫描所选 WSL 环境的 OpenCode 2；勾选工具并选择项目后连接；模型继承原配置；已配置实例自动加载 | 空配置通过空格选择；连接真实服务；扫描/连接产生的模型任务数 0；当前 CLI 实例可直接出现 | M1 |
| D03 Agent 管理 | 名称、项目、原生 Agent、实际模型、在线/健康/忙碌；默认目标、启停、只读检查与真实回复验证 | 显示真实后台状态；检查不调用模型；真实验证明确主动触发；停用不终止已有任务 | M1 |
| D04 任务看板 | 待开始、进行中、等待处理、已完成；搜索、状态和 Agent 筛选；失败、取消和未知结果单独标识 | 分栏和状态与 CLI 一致；未知保留占位；结果不凭传输成功推定 | M2 |
| D05 任务与续问 | 窗口内新任务、每轮回答与事件、原会话续问、历史重返 | 两轮真实执行绑定同 Session，第二轮保持上下文且回答独立；重返不增加 Prompt | M2 |
| D06 等待与取消 | 文件修改一次允许/拒绝、按字段填写原生表单、明确取消当前轮次 | 实际 edit 等待可批准；等待时取消，未批准的修改未发生；确认收据与终态分开 | M3 |
| D07 不明操作 | 写前持久化请求 ID；不明回应展示原请求/操作查询；原任务只读核对 | 不自动重发 Prompt；未知结果不能新 ID 重试；关闭窗口不取消后台任务 | M3 |
| D08 交付 | Windows 程序、构建方式、安装/操作说明、工程与实际 Windows 验收记录 | 提供本机可运行产物；工程检查通过；真实 Windows 截图与任务证据可核查 | M3 |

## 指标定义

- 页面数据每 1.25 秒发起快照，上一轮未完成不并发轮询。后台确认变更至界面可见的延迟：20 次样本 p95 ≤2 秒；冷启动另列，不承诺首次打开 ≤2 秒。
- UI/CLI 任务状态、每轮回答、会话关联一致；重复提交的原生调用次数为 1。
- 扫描、连接、查看、切换主题与历史重返不调用模型；真实任务与主动验证会使用 OpenCode 已有供应商配置。
- 断开时显示最后同步时间、离线提示和缓存标记；不把缓存在线当作新确认。首次启动失败不误显示为“没有配置”。
- 键盘可进入按钮与表单；Tab 保持在当前弹窗；Escape 关闭最上层弹窗；取消弹窗关闭不取消任务。

## 支持范围

本轮交付 **Windows 桌面 + WSL 中的 Bridge/OpenCode**。Windows 端不需要额外安装 Node；WSL 中需要 Node 22.13+ 和 OpenCode 2。程序自动启动通信宿主，已启用的 Bridge 由已有控制器管理。Windows 原生 OpenCode 后台尚未适配，运行环境选择待用户答复；不能把 Linux 的进程身份核验和 Unix socket 当作 Windows 支持。

看板展示最近 100 项任务，不提供全量分页、成本统计或跨设备服务发现。没有任务时使用真实空状态。智能主 Agent/成员委派属于 I05。
