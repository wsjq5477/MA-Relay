# I04 Windows 桌面看板

日期：2026-10-09。用户已要求开发前端看板，并交付 Windows 程序，外观参考最新版 CC Switch。本轮把看板入口确定为桌面窗口。

## 交付目标与增量

| 增量 | 可使用的交付 | 验收条件 |
| --- | --- | --- |
| M1 桌面与连接 | Windows x64 程序、中文侧栏、深浅主题、首次发现/连接、沿用现有实例 | 实际 Windows 进程可打开；只读扫描不调用模型；连接状态来自真实后台，失败给出原因 |
| M2 看板与会话 | 总览、按状态查看任务、搜索/筛选、事件/回答详情、提交与续问 | 同一窗口完成新任务和续问；每轮独立回答；状态与 CLI 同一数据源 |
| M3 控制与交付 | 权限/文本填答、取消、只读对账、重返历史、构建产物/操作说明 | 写前保存幂等 ID；界面关闭不停止原任务；失败不重复提交；工程和真实桌面闭环有证据 |

默认先复用当前已有的 WSL OpenCode/Bridge 实例，Windows 桌面通过 WSL 中的受限 host 调用现有控制器，用户不需要保持终端打开。Windows 原生后台涉及 named pipe、ACL 和进程身份替代，不能把现有 `/proc` 实现直接包装为原生兼容；运行环境选择已向用户询问，按答复调整接入范围。未验证的平台不标为支持。

## 模块与页面

| 页面/模块 | 功能与交互 |
| --- | --- |
| 总览 | 实际连接数、活动/等待/未知任务数；最近会话；待处理任务入口；无记录时说明如何开始 |
| Agent 连接 | 名称、项目、运行环境、真实模型、连接/工作/检查状态；发现并勾选连接；只读检查；明确触发真实验证；启停、默认目标 |
| 任务看板 | 待开始、进行中、等待处理、已完成分栏，失败/取消/未知清楚标识；搜索、状态和 Agent 筛选；打开详情 |
| 会话 | 标题、项目、轮数、时间；历史轮次、当前回答与工具事件；新建/续问；取消和只读核对 |
| 设置 | 深浅主题/系统主题；运行环境与实例路径；后端连接诊断；关闭窗口与停止后台分开 |
| 桌面 host | 结构化消息校验、已有 controller IPC 复用、只读发现、连接配置映射；不在前端暴露凭据或执行任意 shell |
| Windows 壳 | 单实例、窗口控制、隔离 preload、固定 IPC 白名单；打包程序、后台通道恢复；不重建另一个任务数据库 |

## 外观参考

参考截至 2026-10-09 的 [CC Switch 正式版 3.20.4 / 预览版 4.0.2](https://github.com/farion1231/cc-switch/releases)，尤其 [4.0.2 官方主题实现](https://github.com/farion1231/cc-switch/blob/v4.0.2/src/index.css)：中性色背景、浅灰侧栏、紧凑卡片、细边框、黑白主按钮与橙色主题强调、深浅模式。使用 AgentBridge 自身名称与图形，不复制 CC Switch 的商标或赞助内容。

技术采用 Electron + React/TypeScript。现有后台、协议和台账继续使用，前端呈现同一套功能。Windows 产物按实际构建与运行结果记录；仅 Linux 前端编译通过不算 Windows 验收。

## 本轮指标与边界

- 额外必需常驻终端 0；内部 Task/Execution ID 不作为主流程输入。
- UI 快照刷新目标 ≤2s；加载/离线/重连/错误有明确反馈，无伪造在线、随机任务或模拟统计。
- 同一次提交/回复/取消最多一套幂等 ID；结果未知时查询原请求/操作，不换 ID 补发。
- 真实任务、等待、取消和历史与现有 CLI 对照；关闭/重开不重复发 Prompt。
- 连接向导只询问必要的项目和发现目标，模型继承已有原生配置，不重复要求模型 Key。
- 不新增智能主 Agent 委派、供应商代理/切换、MCP 管理或虚构成本统计。I05/I06 按原计划处理；Windows 原生 Agent 范围按用户选择明确记录。
