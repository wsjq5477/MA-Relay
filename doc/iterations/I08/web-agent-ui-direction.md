# Browser接入设置的界面约束

2026-10-30；延续现有桌面配置界面，不替换产品视觉系统。本页是开发设计说明，验收结果统一写入[开发台账](web-agent-development.md)。

用户在桌面配置浏览器接入，在扩展完成本机配对和站点授权，然后由已授权的原生Agent发起任务。界面模式为Operate，首要问题是“这个浏览器是否已接入原机器，下一步需要做什么”。不增加网页日常聊天、模型选择、账号密码或Token表单。

对象与场景清单：

- 机器：Windows/Linux/SSH，浏览器与所选Node须在同一设备；WSL尚无独立网页配对宿主。
- 扩展：使用完整扩展ID登记，不按显示名猜身份。
- 配对：一条原operationId、一个原browserInstanceId；pending/committed/revoked分开显示。
- 状态：认证连接、网页权限、真实账号登录与实际回复分别判断。
- 首次动作：复制扩展ID、生成短期包、复制包、在扩展连接、授予站点访问、扫描并接入节点。
- 恢复动作：页面重开只查询原配对，不将not_found视为重新创建许可。
- 秘密：配对包只在内存/剪贴板流转，不出现在URL、日志、持久UI意图或截图。
- 用户暂停：关闭运输并保留身份和unknown，不当作网页任务取消。
- 撤销：先在原行显示具名确认，再撤销原配对，不结算原Task。
- 运行：保留原网页，不与用户草稿/导航争用；不支持时解释下一步。

视觉继承自[桌面现有实现](../../../desktop/src/workbench.css)和[设置布局](../../../desktop/src/workspace-pages.css)：IBM Plex Sans与Plex Mono，本地字体及原OFL授权，平面浅/深主题，单列分区与标签/内容双列，细分隔线、常规字号和可见焦点。扩展使用同一组字色/表面/强调色；390px堆叠字段，按钮与输入至少44px高。没有方向重抽、外部图片或新增视觉系统；配对状态与原身份是本功能自己的界面内容。

已有设置页截图与当前CSS共同提供视觉依据。Taste按“现有组件/局部功能”分支沿用系统，Impeccable按“Extend an existing surface”工作，不新增PRODUCT.md或改写未存在的全局DESIGN.md。界面完成后运行真实扩展/生产桌面渲染的交互、截图和机械检查；界面证据不推导Provider可用或原生模型准出。
