# 迭代三最终交付与 I03B 验收报告

日期：2026-10-08。状态：**I03A 体验修正和 I03B 的 B01–B06 已完成开发及本轮工程、真实 CLI/OpenCode 验收，可供用户使用。** 人工签收由用户试用决定。I04–I06 仍按后续计划执行。

## 1. 使用入口与交付

运行 `agentbridge` 进入中文菜单。首次启动自动发现 OpenCode，空格勾选、回车连接；已有启用连接自动连接。高级配置为单独入口。一个终端可提交需求、查看回答、处理权限或文本输入，以及管理持续会话。

| --- | --- | --- |

| B02 显式取消 | 运行与等待任务可取消；操作收据和实际“已取消”分开；完成竞态保留成功；取消 ID 共用执行占位，未知响应不补写 | 真实运行/权限等待取消；受控五次重复、不同 ID、丢回应与竞态 |

| B05 异常后台 | 持久化受保护进程身份；后台被强杀后复用自己托管的原服务；确认旧服务死亡才安全重启；不凭端口猜归属 | 真实 SIGKILL/死服务重启；身份篡改、PID/启动时间不符、外部服务和父进程管道故障回归 |

提交新任务使用菜单“提交任务”；在已有会话里选择“继续追问”才能延续上下文。上一轮成功、失败或确认取消后允许续问。运行、等待、unknown 占位期间拒绝同项目的新执行；改变模型、目录或 Agent 后旧会话不可静默换配置续问。

自动化入口：`agentbridge conversations`、`conversation ID`、`continue ID "需求" --watch`、`cancel TASK_ID`、`reconcile TASK_ID`。这些命令使用本机后台，支持 `--dir`；保留 requestId/operationId 查询路径和 JSON 输出。详细运行说明见 [README](../../../README.md)。

## 4. 交付指标

| 指标 | 目标 | 最终实测 |
| --- | --- | --- |
| 同原生 Session 连续对话 | 至少 3 轮，关联错误 0 | 3 轮，上下文正确，每轮独立回答 |
| 正常退出重返 | 额外 Session/Prompt 0 | 额外 Prompt 0 |

| 原生已确认死亡重启 | 原生历史保留、不补发 | 新 PID，原 Session 和三轮消息保留，额外 Prompt 0 |
| 真实取消 | 运行、权限等待各 1 次 | 均确认中断；等待取消无文件改变 |
| 持久事件与执行 | 事件丢失/重复应用/自动重投 0 | 受控故障断言通过；真实六轮 invocation 均为 1、seq 均已 ACK |

| 日常额外必需终端 / 手改配置 | 0 / 0 | 0 / 0 |
| 本轮已知凭据泄漏 / 错误释放占位 | 0 / 0 | 0 / 0 |

623ms 从新后台启动到注册并恢复观察计时；231ms 测后台已确认的连接描述到持续状态终端显示。均不含模型生成时间，不保证任意网络/原生故障都在此时间内取得终态。

## 5. 当前可用实例与边界

用户默认实例已从旧后台正常升级，`OpenCode` 显示 online/healthy/available，新增 cancel 能力和会话命令可用。原 Agent、项目目录、权限和继承模型 `opencode/exo-free` 保持；本次检查没有提交模型 Prompt，连接可用不代替该模型的真实回复验证。

无法证明归属的旧原生服务不能自动接管；缺绑定或记录的历史 unknown 继续保留占位并显示核对原因。取消不会撤销已经发生的文件修改。资源锁限同一 Hub 的派发，不约束另一实例或用户直接运行原生 CLI；项目目录不构成新增文件系统沙箱。

真实文本表单已验证 API→CLI→回复链路；模型自主生成表单仍未核验。I03A 真实拒绝确认无文件变化，但该轮模型完成未确认，报告保留实际状态。Windows 原生、跨设备、看板与智能主 Agent 委派留在后续迭代。

前几次失败验收材料及输出修正前的通过记录保留在 `artifacts/I03B-first-*`、`second-*`、`third-*`、`fourth-*`、`before-output-polish-*`。它们用于追溯测试等待竞态、父进程管道及旧端口释放问题；最终结论依据最后的通过材料。
