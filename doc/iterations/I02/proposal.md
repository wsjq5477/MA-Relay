# 迭代 2 范围确认提案：通过 CLI 使用真实 OpenCode

日期：2026-10-08。状态：用户已确认目标与六项需求，并批准开发；现已实现并通过本机真实验收，待用户复核。需求规则与实现设计分别见 requirements.md、design.md，证据见 testing.md。

用户反馈：I01 的 Mock 与状态查询难以人工感知实际价值，希望尽早调用真实 Agent 并用于自己的项目。原计划为 I02 可靠性与控制、I03 真实 OpenCode、I04 看板。本提案建议将基础真实接入提前到 I02，完整恢复与控制放到 I03；未确认前不替换既有迭代计划。

本机已检测到 OpenCode 2.0.24。安装完成不代表模型配置与真实任务已验收；开发与真实验收进度见 development.md、testing.md。

## 1. 本轮交付目标

**用户在一台 Linux/WSL 主机上，通过 AgentBridge CLI 向一个固定项目目录中的真实 OpenCode 提交任务，观察执行进度，取得真实回答，并核对文件修改与实际测试结果。**

一次完整的人工使用流程：

1. 配置本机 OpenCode 和一个项目目录，检查运行条件。
2. 用一个组合启动入口启动本地 Bridge，发现真实 Agent。
3. 提交“分析这个项目”或“修改一个功能并运行测试”。
4. 在 CLI 观察真实进度；遇到原生权限或输入等待时获得明确提示和可操作的处理入口。
5. 查看最终回答、任务状态及原生会话关联，核对项目内的文件与测试结果。
6. 退出并重启 Bridge，查询已保存的任务结果。

本轮交付一个真实 Agent；每个任务新建原生会话，Agent 串行执行。模型和工具由 OpenCode 提供，Hub 不直接调用模型。

## 2. 已确认需求

| 编号 | 需求 | 用户获得的功能 | 本项验收条件 |
| --- | --- | --- | --- |
| I02-F01 | 配置与启动检查 | 配置 OpenCode 连接和固定项目目录；检查版本、连接、认证、目录与模型可用条件 | 正确配置能通过检查；连接失败、无效目录、认证失败或缺少模型条件时，指出失败项及处理方法，不输出凭据 |
| I02-F02 | 真实任务提交 | 选择真实 OpenCode Agent，提交文本任务，取得 Task ID；每次任务新建原生会话 | 至少 2 个任务分别对应独立原生会话；真实 Prompt 和回答可核对；同一幂等请求不产生第二次执行 |
| I02-F03 | 可读的执行观察 | 提交后持续观察进度、可获得的工具活动及最终回答；保留 JSON 查询 | 至少 1 次分析与 1 次修改任务能在 CLI 观察；最终回答来自对应会话；任务结束后观察命令退出，不反复打印整份任务 JSON |
| I02-F04 | 项目修改与等待处理 | 在固定项目目录执行修改、运行检查；显示原生权限或输入等待及处理入口 | 示例文件发生预期变化；至少 1 次真实测试或检查有命令与输出证据；等待可被识别、处理并继续，不能静默挂起或提前报成功 |
| I02-F05 | 简化启动与历史查询 | 提供一个本地组合启动入口；查看任务列表、详情、最终结果及原生会话标识 | 操作者按文档完成启动、提交、观察、查历史；停止时仅关闭 Bridge 自己启动的进程；重启后已保存结果仍可查询 |
| I02-F06 | 失败与执行不明的保护 | 区分明确失败和无法确认结果；保留任务与原生会话关联；继续保持不自动重跑 | 模型报错不显示成功；运行中断开 Bridge 后，无法确认的任务为 unknown；Bridge 不自动重复提交原生 Prompt；I01 身份、幂等、持久化与隐私用例继续通过 |

权限与输入处理需要依据安装版本确定入口。范围要求是操作者能够完成处理；统一的 Bridge 回复命令、全部原生交互类型和任务取消接口在 I03 完善。I02 不通过默认自动批准全部权限来满足验收。

## 3. 整轮验收：一次可重复的真实演示

使用独立示例项目，准备一个文件和一条可执行的测试命令。验收必须同时完成：

| 场景 | 交付指标与证据 |
| --- | --- |
| 启动与发现 | 按文档使用一个组合入口启动；CLI 显示真实 Agent、类型和目标项目 |
| 分析项目 | 1 个真实分析任务完成；回答包含可在项目内核对的信息；记录 Bridge Task ID 与原生 Session ID |
| 修改并测试 | 1 个真实修改任务完成；文件变化符合预定需求；测试实际执行，记录命令、输出与结果 |
| 权限或输入等待 | 至少 1 次真实等待可见；操作者按提示处理后任务继续；处理入口与步骤写入使用说明 |
| 任务隔离 | 分析与修改任务的原生会话不同，事件与回答不串用 |
| 重复提交 | 同一幂等键、相同内容重复提交 5 次，只有 1 个 Bridge 任务及 1 次原生 Prompt 提交；同键不同内容拒绝 |
| 历史保存 | 上述已完成任务重启后查询，状态与已保存回答丢失数为 0 |
| 故障保护 | 运行中断开 Bridge，无法查证时为 unknown，自动重新提交次数为 0；原生错误有明确失败原因 |
| 工程回归 | lint、typecheck、test、build 通过；离线测试与真实 Agent 验收分别记录 |

真实验收记录 OpenCode 版本、脱敏配置摘要、示例项目、任务/会话关联、文件变化与测试输出。离线夹具和 Mock 不计为真实 Agent 验收通过。

任务完成耗时受模型与项目影响，本轮记录实测值，不设模型响应时间或吞吐量 SLA。
